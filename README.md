# Lab Equipment Booking System

## Project Overview

The Lab Equipment Booking System is a web-based application developed using Python and Flask to manage shared laboratory equipment and booking requests.

## Main Features

- User accounts and login
- Equipment catalogue
- Equipment availability management
- Booking requests
- Database management
- Automated testing

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML and CSS
- pytest
- Ruff

## Installation

Clone the repository:

```bash
git clone https://github.com/nirmanijayakodi0-afk/lab-equipment-booking.git
cd lab-equipment-booking
```

Create and activate a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

## Testing

Run automated tests:

```bash
python -m pytest -v
```

Run code quality checks:

```bash
ruff check .
```

## Project Status

The project is under development, with accounts and login, the equipment catalogue, and booking requests among its main priorities.
