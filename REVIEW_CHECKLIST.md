# Pull Request Review Checklist

Review this checklist before merging a pull request into the main branch.

## Code Quality
- [ ] Code is readable and follows project conventions.
- [ ] Variable and function names are meaningful.
- [ ] No unnecessary or duplicate code exists.

## Functional Requirements
- [ ] User inputs are validated.
- [ ] Business rules and conditions are correct.
- [ ] Database operations are appropriate.
- [ ] Login and role restrictions are checked.
- [ ] Errors are handled appropriately.

## Security
- [ ] No passwords or secret values are committed.

## Testing
- [ ] Relevant automated tests have been added or updated.
- [ ] Existing tests still pass.
- [ ] Ruff checks have been completed.

## Review Outcome
- [ ] Approved
- [ ] Changes requested
